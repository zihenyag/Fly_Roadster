# FLY! Roadster

桌面浏览器中的第一人称无尽驾驶游戏。Three.js 渲染驾驶舱、完整车身和三面实时镜面，Rapier 负责刚体、连续碰撞和悬挂探测。无音乐；车辆音效与中文导航语音可以分别关闭。

## 本地运行

```sh
npm install
npm run dev -- --port 5173
```

打开终端打印的本地地址。鼠标点击开始、继续、设置或重开。

| 操作 | 按键 |
| --- | --- |
| 左／右转向 | D／F |
| 油门／刹车 | J／K |
| 起飞 | QWERTYUIOP、左右方括号中的任意键 |
| 抓地 | ZXCVBNM、逗号、句号、斜杠中的任意键 |
| 加重当前操作 | 同时按住空格 |
| 暂停 | 任何其他键；H 也只暂停 |

同组多键不叠加力度。方向与踏板有平滑响应，高速转向自动收敛。空中油门和刹车无效，车速自然衰减；姿态翻倒时辅助自动开启，只翻正，不自动导航。

方向盘采用开口平底造型和橙色定位标，地面与空中均随转向旋转；驾驶屏同时显示有符号的转角。驾驶屏、中屏使用独立圆角网格，与各自外壳共同倾斜。外后视镜位于车门外侧，并有独立碰撞体。

推进燃料上限100，每游戏秒恢复6；起飞消耗14／28，抓地8／16，辅助工作时4。耗尽后需积累少量燃料才能重新输出，暂停不回充。

## 道路与交通

- 车道宽4.6米，Roadster车身宽约2米；后视镜有独立碰撞体。
- 每局随机种子，至少提前4 km规划道路。前300 m只有正常道路和车流。
- 岔路、半圆环、必须跨越的护栏提前2 km导航提示；不播报危险车辆。
- 只有导航授权时才能跨越护栏。半圆环必须经过倒挂顶端，再飞到侧面接续道路。接续高架与旧路分层，避免返回路线互相穿越。
- 普通交通包括小客车、两厢车、面包车、小货车、大货车和半挂牵引车，会跟车、打灯超车；事故后留下动态刚体障碍。
- V800从后方高速逼近；SU7切入前方后失控。险车和有意安排的交通事故在出现前，使用独立物理快照回放避险方案，不通过则不投放；不会在进入画面后挪车救场。
- 任何擦碰、重摔、走错路线或未经授权抄近路都会结束旅程。正常轮胎接地不算事故。

## 验证

```sh
npm test
npm run verify
npm run build
```

`npm test` 覆盖输入、燃料、随机生成、自动辅助、环面约束、车道转向、空中方向盘、车辆事故及险车避险回放，并检查飞跃轻落地可通过、无缓冲重落地会失败。

`npm run verify` 检查1,000个种子各30 km的生成约束；使用与游戏相同的物理引擎和可由功能键产生的轻重输入，回放50个种子各20 km。长距离回放不包含随机交通，交通接触与险车准入另行测试；结果写入 `artifacts/verification.json`。这组检查不是对任意玩家状态或所有无限随机组合的数学证明。

车型使用程序化原创近似模型，并非厂商CAD。桌面宽屏是首版支持的平台；浏览器不提供中文语音时仍保留文字导航。构建产物在 `dist/`，可以静态托管。

## GitHub Pages

项目完全在浏览器运行，不需要后端，不保存历史纪录或游戏存档。资源使用相对路径，可部署在 GitHub Pages 的仓库子目录。

仓库为 `zihenyag/Fly_Roadster`。推送到 `main` 后，`.github/workflows/pages.yml` 会运行测试、构建并发布 `dist/`。也可在 Actions 中手动运行部署。首次部署前，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，然后运行工作流。

预期访问地址为 `https://zihenyag.github.io/Fly_Roadster/`；实际部署状态以 GitHub Actions 的部署结果为准。仅上传 TypeScript 源文件或双击打开 `index.html` 不能替代构建与静态托管。
